# Victorious Tether

Victorious Framework tethering and hidden-hotspot app for Android. HTTP/SOCKS5 proxy tether without root, plus a root "Stealth" mode with a hidden SSID.

See [GUIDE.md](GUIDE.md) for modes, architecture, limits and what is still unverified on hardware.

```bash
./gradlew testDebugUnitTest assembleDebug lintDebug
```
